## ╨б╤В╨╡╨║

### Backend
- Python 3.12, FastAPI, Uvicorn
- python-chess (chess engine API)
- Stockfish (╤Б╨╡╤А╨▓╨╡╤А╨╜╤Л╨╣, ╨┐╤Г╨╗ ╨▓╨╛╤А╨║╨╡╤А╨╛╨▓)

- PyJWT, Pydantic v2

### Frontend (╨╛╨┐╤Ж╨╕╨╛╨╜╨░╨╗╤М╨╜╤Л╨╣ WebApp)
- React 18, TypeScript 5, Vite 5
- react-chessboard, chess.js
- Zustand
- TailwindCSS
- Telegram WebApp SDK

### Infrastructure
- Docker Compose
- Nginx (reverse proxy ╨┤╨╗╤П REST + WebSocket)
